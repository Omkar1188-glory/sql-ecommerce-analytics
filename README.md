# SQL E-Commerce Analytics Project

## 📌 Project Overview
This project simulates a real-world **e-commerce database system** using SQL.
It covers **database design, data insertion, querying, analytics, and schema evolution**.

The project is structured to clearly show:
- How data is stored
- How data is analyzed
- How SQL skills were practiced step by step

This repository is suitable for **Data Analyst / Data Scientist / SQL-heavy roles**.

---

## 🗂 Repository Structure

sql-ecommerce-analytics/
│
├── schema.sql        → Database & table creation + schema changes  
├── data_insert.sql  → Realistic data insertion  
├── practice.sql     → Learning & practice queries (checkpoints 3–9)  
├── analytics.sql    → Final business analytics queries  
└── README.md

---

## 🧱 Database Schema

Tables used:
- `customers`
- `categories`
- `products`
- `orders`
- `order_items`

The schema follows **normalized relational design** to avoid data redundancy.

---

## 🛠 SQL Skills Demonstrated

### Core SQL
- `SELECT`, `WHERE`, `ORDER BY`, `LIMIT`
- `INSERT`, `UPDATE`, `DELETE`

### Advanced SQL
- `GROUP BY`, `HAVING`
- Aggregate functions (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`)
- `JOIN` operations
- Schema evolution using `ALTER`, `DROP`, `TRUNCATE`

---

## 📊 Business Analytics Covered

- Monthly revenue trend
- Top customers by spend
- Best-selling products
- Category-wise revenue
- City-wise revenue
- Customers with no orders
- Repeat customers
- Order status analysis

All final insights are written in **analytics.sql**.

---

## 🧪 Practice & Learning Evidence

The file **`practice.sql`** contains:
- Query experiments
- Filtering practice
- Aggregation practice
- Safe update & delete examples
- Schema modification practice

This file demonstrates **hands-on SQL learning**, not just final answers.

---

## 🚀 How to Run This Project

1. Execute `schema.sql`
2. Execute `data_insert.sql`
3. Run queries from `practice.sql` (optional)
4. Run business queries from `analytics.sql`
